# Проект: Product & Category

## 📌 Описание

В проекте реализованы классы для работы с товарами и категориями.

* **Product** — описывает товар
* **Category** — описывает категорию товаров

Проект демонстрирует работу с:

* классами и объектами
* инкапсуляцией (приватные атрибуты)
* свойствами (`@property`)
* магическими методами (`__str__`, `__add__`)
* методами класса (`@classmethod`)

---

## ⚙️ Функциональность

### 🛍️ Класс Product

Хранит информацию о товаре:

* название
* описание
* цена
* количество

#### Особенности реализации:

* цена хранится в приватном атрибуте `__price`
* доступ к цене осуществляется через `@property`
* setter для цены:

  * запрещает устанавливать значение ≤ 0
  * при понижении цены требует подтверждение пользователя

#### Дополнительно:

* `new_product()` — создание объекта из словаря
* `__str__()` — удобный вывод информации о товаре
* `__add__()` — подсчёт общей стоимости товаров (цена × количество)

---

### 📦 Класс Category

Хранит:

* название
* описание
* список товаров

#### Атрибуты класса:

* `category_count` — общее количество категорий
* `product_count` — общее количество товаров во всех категориях

Обновляются автоматически при создании новой категории.

#### Методы и свойства:

* `add_product()` — добавление товара в категорию
* `len_products` — количество товаров в категории
* `__str__()` — вывод общего количества товаров (с учётом quantity)

## 💡 Пример использования

```python
from src.product import Product
from src.category import Category

product = Product("Iphone 15", "512GB", 210000.0, 8)

category = Category("Смартфоны", "Описание", [product])
category.add_product(Product("Samsung", "Описание", 100000, 5))
```

---

## ⚠️ Ограничения и особенности

* `Category.products` реализован как property и выводит товары в консоль, а не возвращает список
* `__add__` в Product работает только с объектами Product
* при понижении цены используется `input()` (интерактивное поведение)
* `product_count` считает количество товаров без учёта их `quantity`
